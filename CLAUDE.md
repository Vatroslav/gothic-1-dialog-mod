# Gothic 1 Remake: Dialog Options Offset

Script-only ModKit mod. `DialogOptionsOffset/` is the mod package; only that folder goes to `G1R/Mods`.

## Rules

- **No spoilers.** Vatra is playing the game for the first time. Game scripts, docs and sample mods contain character, quest and chapter names. Never write those in chat, commits or files unless Vatra mentioned them first. Use UI names only.
- Repo content (code, README, commits) is in English. Chat with Vatra is in Croatian.
- Writing outside `~/github` needs Vatra's explicit yes each time. This includes copying to `G1R\Mods`, launch options, `Mods.ini` and other mods in Vortex.
- Don't publish the mod to Nexus or Steam Workshop.
- Only Vatra can confirm the mod works, by seeing it in his game.
- Scope is one adjustable horizontal offset. No centering, styling or extra features unless Vatra asks.
- Other mods' code is a reference only: don't copy it without checking its license.
